# Show Your Work — shared internals (`syw-common`)

Shared code, styles and trust lists used by [`syw-react`](https://www.npmjs.com/package/syw-react) and [`syw-svelte`](https://www.npmjs.com/package/syw-svelte). It's installed automatically as their dependency.

This package isn't meant to be imported directly and isn't a supported API. Use `syw-react` or `syw-svelte` instead.
